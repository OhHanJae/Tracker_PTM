제어 우선권 사용 시 PLC 레이저 모드와 관계없이 PTM 수동·자동 제어를 사용합니다. 체크 상태는 즉시 저장됩니다.

            
바이패스에서는 레이저 출력을 차단합니다. 설정은 서버 재시작 후에도 유지됩니다.

            
RDK X5 물리 핀 31 · HIGH=ON / LOW=OFF. 포인트 이동 중 OFF, 실제 완료 후 허가된 출력만 ON.

수동 ON은 자동 OFF·절전 중에도 최대 30분 허용합니다. 이동·Jog·원점·정지 등 다음 장치 제어 명령에서 OFF 후 자동으로 복귀합니다.
