# 작업자 조립 기준과 서보 XYZ 보정 준비

## 작업자와 제품의 기준

도면 그룹과 레시피를 선택한 뒤 **작업자·제품 0° 기준 / PTM 위치 설정**을 연다. XYZ는 원본 CAD 좌표계의 mm이며 도면 좌표 자체를 다시 쓰지 않는다.

- 제품 기준점: 회전·틸팅 중심이다. 기본은 제품 포인트 범위의 중앙이다.
- 작업자 위치: 발 위치 XYZ와 키다. 작업자는 제품 기준점을 바라본다. 기본 위치는 제품 긴 축의 한쪽 전면이다.
- 기본 0° 자세: 원본 CAD에서 조립 초기 방향으로 돌려 놓을 회전·틸트 오프셋이다. `기본 0°의 회전`을 180°, 틸트를 0°로 저장하면 그 자세가 상대 0°/0°다. 이후 회전 입력 10°는 기본 방향에서 추가 10°를 뜻한다.
- 회전 +: 바닥 수직 Z축을 중심으로 위에서 내려다볼 때 시계방향이다.
- 틸팅 +: 0° 기준 자세에서 제품의 +Z 전면이 작업자쪽으로 오는 방향이다. 긴 축을 중심으로 회전하며 회전각을 바꾸면 틸트축도 제품 방향을 따라간다.

**작업자 시점** 버튼으로 제품을 확인하고 좌우 회전·틸팅의 부호를 확인한다. 원근 카메라 시점 변경은 제품 각도 변경과 별개다. 기준점·작업자 위치·기본 자세를 변경하려면 상대 회전과 틸팅을 0°/0°로 돌린 뒤 저장한다. 기준 설정은 선택 레시피에만 저장하며 다른 레시피의 기준을 덮어쓰지 않는다. 기본 방향을 바꾸어도 원본 CAD XYZ와 상대 영점에서 티칭한 Pan/Tilt는 유지한다.

회전·틸트 입력 위에서 휠을 위로 돌리면 +0.1°, 아래로 돌리면 −0.1°다. Ctrl을 누르면 1°씩 조정한다. 도면 각도, 레시피 보정 각도, 기본 자세 각도 입력에 적용한다. 입력 즉시 3D 모델·포인트·모의 조사선에 미리보기하며, 시점과 포인트 선택을 유지한다. 화면의 **미저장 · 장치 이동 없음** 안내를 확인한다. 캘리브레이션/보정 적용/설정 저장을 눌러야 해당 값이 저장된다.

기존 축/부호로 비영점 보정된 레시피는 저장된 이동값과 일치하도록 이전 자세를 표시하고 안내한다. 새 기준은 자세 보정을 명시적으로 다시 적용할 때 사용한다. 저장된 원본 XYZ와 최초 기준점 Pan/Tilt는 유지한다.

## PTM이 아래에서 위로 보이는 경우

기준점 각도로 추정한 가상 원점은 실제 지그의 전면 방향이나 설치 높이를 보장하지 않는다. 자동 추정 표시에는 **PTM 설치 방향**을 별도로 적용한다. 기본값은 **상부 → 하향 조사**이며 제품 기준 Z보다 위에 표시한다. **하부 → 상향 조사**, **추정 위치 그대로**도 선택할 수 있다. 이 조건은 모형의 표시 제약이며 실측 외부 파라미터가 아니다. 실제 좌표를 알고 있다면 직접 지정한다.

1. **PTM 표시 위치 → 직접 지정(표시용)**을 선택한다. PTM XYZ 입력을 편집하면 이 모드로 자동 전환한다.
2. PTM XYZ를 입력하거나 **PTM을 작업자쪽 전면에 배치**를 누른다. 이 버튼은 작업자와 제품 사이, 제품 기준 높이보다 250mm 위를 초기 표시값으로 넣는다. 실제 위치에 맞게 다시 조정한다.
3. **표시 미리보기**에서 작업자·제품·PTM 관계와 모의 조사 방향을 확인한다.
4. **선택 레시피에 저장**을 누른다. 저장 전에 캘리브레이션을 눌러도 편집한 설정을 함께 저장한다. 캘리브레이션이 실패하면 설정도 저장하지 않고 편집값을 유지한다. 저장한 수동 위치는 재캘리브레이션·재시작 후에도 유지한다. 자동 추정을 다시 쓰려면 모드를 명시적으로 바꾼다.

수동 PTM XYZ는 뷰어 전용이다. 현재 포인트의 실제 Pan/Tilt 계산은 기존 기준점 캘리브레이션을 사용한다. 화면의 모의 조사선은 실제 레이저 출력 피드백이 아니며, 표시 미리보기·설정 저장은 장치를 이동시키지 않는다.

## 서보 보정은 준비 단계

서보 입력은 엔코더·펄스 등의 원시값이다. **서보 XYZ 보정 준비**에서 다음을 저장한다.

| 항목 | 의미 |
|---|---|
| 기준 원시 X/Y/Z | 제품 기준점에 대응시키는 원시값 |
| mm/원시값 계수 | 축별 단위 환산. 축 반전이 필요하면 음수 사용 가능. 0은 불가 |
| 입력 원시 X/Y/Z | 계산 미리보기에만 사용하는 다음 입력값 |

계수는 미설정으로 시작한다. 설정을 저장한 뒤 계산 미리보기를 실행한다. 각 축의 `(입력 원시값 − 기준 원시값) × 환산계수`를 제품 기준점에 대한 고정 XYZ 좌표로 해석하고, 기본 자세에서 현재 상대 회전·틸팅으로 변환한다. 상대 0°/0°에서는 기본 자세 오프셋과 관계없이 원시값이 그대로 돌아온다. 결과는 회전된 XYZ(mm)와 원시 단위로 환산한 보정값이다. 예를 들어 기준 원시값 0, 계수 1일 때 `[100, 0, 0]`에 회전 +90°를 주면 기준점 상대 좌표는 `[0, -100, 0]`이다.

이는 직교 XYZ 점 좌표를 가정한 준비용 계산이다. 실제 축 기구학, 엔코더 카운트의 물리 방향, 기계 영점·이동 한계, 통신 주기와 필터는 아직 연결하지 않았다. `automatic_enabled`는 항상 false이며 PLC 구독, 원시값의 자동 수신, 레시피 포인트 자동 갱신, 서보 명령 출력은 수행하지 않는다.

## API와 저장 범위

- `drawing.assembly_setup`: drawing_id, 현재 recipe_id, setup을 받아 선택 레시피의 `drawing.assembly_setup`에 저장한다. 이동·조그·스캔·시험 중 저장은 거부한다.
- `drawing.servo_preview`: drawing_id, 현재 recipe_id, servo_xyz, product_rotation_deg, product_tilt_deg를 받는 읽기 전용 계산이다. 환산계수가 없으면 ready=false와 이유를 반환한다.
- `drawing.calibrate`: 기존 파라미터에 선택적 assembly_setup을 추가했다. 전달하면 같은 저장 작업에 포함하며 recipe_id 검증과 작업 기준 저장의 정지 조건을 적용한다.
- `assembly_setup.zero_rotation_deg/zero_tilt_deg`: 기본 0°의 각도. 각각 ±360°다. `ptm_installation`은 above/below/free이며 기존 설정에 필드가 없으면 0°/0°와 above를 사용한다.
- 도면 응답의 `assembly_setup`과 `pose_frame`이 화면과 보정의 기준이다. `ptm_pose`는 현재 표시 위치, `ptm_calibrated_pose`는 기본 자세·설치 조건을 적용한 추정 표시 위치, `ptm_reference_pose`는 조건 적용 전 원래 추정값이다. 기존 `camera_pose` 호환 별칭도 유지한다.
- 레시피 JSON 및 도면 ZIP을 통해 설정을 함께 보존한다. API 입력의 setup에는 편집 가능한 항목만 넣으며 version/automatic_enabled는 읽기 전용이다.

현장 적용 전에는 실제 작업자 전면·각도 부호·기준점·PTM 설치 위치와 환산계수를 실측 대조해야 한다. 로컬 수학/브라우저 검증은 실제 장치 정확도 검증과 구분한다.
