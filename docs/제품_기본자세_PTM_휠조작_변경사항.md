# 제품 기본 자세 · PTM 표시 · 각도 휠 조작 변경사항

## 변경 전과 후

| 항목 | 변경 전 | 변경 후 |
|---|---|---|
| 제품 초기 방향 | 원본 CAD 방향이 항상 0° | 레시피별 기본 회전·틸트를 지정하고 그 자세를 상대 0°로 사용 |
| PTM 자동 표시 | 각도 캘리브레이션의 추정 원점만 표시하여 하부에 나타날 수 있음 | 상부/하부 설치 조건 또는 추정값 그대로를 선택. 기본은 상부 → 하향 |
| PTM 좌표 편집 | 모드 선택·저장을 놓치면 캘리브레이션 응답으로 편집값이 사라질 수 있음 | XYZ 편집 시 수동 모드 자동 선택. 미저장 설정을 캘리브레이션과 함께 저장 |
| 각도 조정 | 숫자 입력 후 적용 결과를 확인 | 휠 0.1°, Ctrl+휠 1° 및 직접 입력 즉시 3D 미리보기 |
| 미리보기 상태 | 전체 포인트 갱신과 시점 맞춤을 거침 | 기존 시점·포인트 선택을 유지하고 제품과 조사선만 갱신 |

## 기본 회전 180°로 사용하는 절차

1. 도면 그룹과 레시피를 선택하고 상대 회전·틸트 입력을 0°/0°로 둔다.
2. **작업자·제품 0° 기준 / PTM 위치 설정**을 연다.
3. **기본 0°의 회전 = 180**, **기본 0°의 틸트 = 0**으로 입력한다.
4. 도면과 작업자 방향을 확인한 뒤 **선택 레시피에 저장**한다. 캘리브레이션을 실행해 함께 저장할 수도 있다.
5. 이후 상대 회전 0°는 기본 방향 180°이며, 상대 회전 +10°는 그 방향에서 위에서 본 시계방향으로 추가 10°다.

기본 자세는 도면의 원본 XYZ를 다시 쓰지 않는다. 기준점 티칭은 설정한 상대 0°/0° 상태에서 수행한다. 기존 비영점 보정의 기준을 바꾸려면 먼저 상대 영점으로 되돌린다.

## 위에서 아래로 조사하는 PTM

자동 표시에는 **PTM 설치 방향 = 상부 → 하향 조사**를 사용한다. 실제 위치를 알고 있다면 PTM XYZ를 입력한다. 좌표 입력은 **직접 지정(표시용)**으로 전환하며, 지정한 위치는 캘리브레이션과 서버 재시작 후에도 유지된다.

자동 표시의 설치 조건과 수동 좌표는 뷰어용이다. 평면의 티칭 각도만으로 실제 설치 위치를 확정하지 않으며, 이 표시 설정으로 실제 장치의 Pan/Tilt를 덮어쓰지 않는다. 실제 포인트 보정은 기준점 티칭을 사용한다. 빨간 선은 선택한 포인트를 향한 모의 조사선이다.

## 저장과 호환

- 새 설정은 선택 레시피의 `drawing.assembly_setup`에 저장한다. 다른 레시피의 설정은 바뀌지 않는다.
- 기존 설정에 기본 각도가 없으면 0°/0°, 설치 조건이 없으면 above를 사용한다. 기존 수동 PTM 모드는 유지한다.
- `drawing.calibrate`의 선택적 `assembly_setup`은 보정과 함께 저장하며, 실패하면 설정도 되돌린다. 기존 호출은 그대로 지원한다.
- 기존 레시피 JSON/도면 ZIP 저장 경로로 설정을 보존한다. 통신 데이터맵은 변경하지 않는다.
- 서보 XYZ는 준비용 계산만 제공한다. 기본 자세를 지정해도 상대 0°/0°의 원시값은 그대로이며, 자동 적용·서보 출력은 연결하지 않았다.

## 검증과 적용

관련 Python 회귀 테스트, 각도 행렬/설정 UI 테스트, 실제 Edge 브라우저의 휠·미저장 설정 보존 테스트, EODCT288 WebGL 미리보기를 검증했다. 이는 로컬 검증이며 실제 장비의 조사 정확도 검증은 포함하지 않는다.

변경 파일을 실행 장비에 반영한 뒤 PTM 서버를 재시작하고 브라우저에서 Ctrl+F5로 다시 불러온다. 이 작업에서는 실행 중인 장치나 서버를 재시작하지 않았다.

상세 설정은 [작업자 조립 기준과 서보 준비](작업자_조립기준_및_서보준비.md)를 참고한다.
