# 웹 콘솔 사용 설명서

PT503/PT510 제어 서버가 제공하는 브라우저 기반 콘솔입니다. 모터 조작, 레시피 관리, 게임패드 조작, 레이저 모듈, 통신 로그, 도면 기반 캘리브레이션을 한 화면에서 테스트할 수 있습니다.

## 1. 실행

| 환경 | 실행 방법 |
|---|---|
| Windows | `run_server.bat` 또는 `python main.py --server --host auto --tcp-host auto` |
| Linux / RDK-X5 Ubuntu 22/24 | `./run_linux.sh` |

기본 접속 주소는 `http://서버IP:8080`입니다. TCP JSON Lines API는 기본 `8765` 포트를 사용합니다.

서버 모드는 PySide6 GUI가 없어도 동작합니다. RDK-X5의 `rdk-x5-ubuntu22-preinstalled-server-3.5.0-arm64.img` 같은 headless 이미지에서는 `./run_linux.sh` 서버 모드만 사용하면 되고, 필수 Python 패키지는 `requirements-server.txt`의 `pyserial`입니다. 원격 접속은 같은 테스트망에서만 사용하는 것을 권장합니다. 현재 내장 서버에는 별도 계정 인증이나 TLS가 포함되어 있지 않습니다.

Linux 보드로 배포할 때는 PC의 `.venv` 폴더를 복사하지 마세요. Windows에서 만든 `.venv/Lib/...` 구조는 Linux/arm64에서 맞지 않습니다. 보드에서 `./run_linux.sh`를 실행하면 `.venv` 또는 `.venv-linux`를 새로 만들고 필요한 서버 의존성만 설치합니다.

## 2. 화면 구성

| 탭 | 주요 기능 |
|---|---|
| 수동·위치 | Pan/Tilt 조그, STOP, 현재 위치 조회, 절대 위치 이동, 모니터링 |
| 레시피·포인트 | 레시피 생성/수정/삭제, 포인트 등록, 순차/랜덤 테스트, 현재 위치 캡처 |
| 도면 캘리브레이션 | STL/STP/STEP/CAD 등 도면 업로드, 3D 뷰어, 도면 포인트 등록, Pan/Tilt 자동 계산 |
| 게임패드 | 브라우저 Gamepad API 기반 수동 조작, 축 매핑, 반전 설정 |
| 레이저 모듈 | Arduino/RS485 레이저 모듈 연결, ARM, ON/OFF, Pulse |
| 프로토콜·고급 설정 | 전체 명령 목록, 파라미터 JSON 편집, 고급 명령 테스트 |
| 통신 로그 | TX/RX 로그 확인, 화면 지우기, JSONL 다운로드 |

## 3. 도면 캘리브레이션 흐름

1. `도면 캘리브레이션` 탭에서 `.stl`, `.stp`, `.step`, `.cad`, `.obj`, `.ply`, `.glb`, `.gltf` 파일을 선택합니다. STEP/STP 원본과 같은 기본 이름의 `.glb`, `.obj`, `.stl`, `.ply` 메시 파일을 같이 선택하면 웹 표시용으로 우선 사용합니다. 메시 파일이 하나뿐이면 파일명이 달라도 자동 연결합니다. 예: `panel.step` + `panel.glb`.
2. `도면 업로드`를 누르면 진행률 바가 표시됩니다.
3. 업로드가 완료되면 서버가 웹 표시용 mesh를 생성하고 파일로 저장합니다.
4. 변환된 도면은 `최근 도면` 목록에서 다시 불러올 수 있습니다.
5. 3D 모델 위를 좌클릭하면 `P1`, `P2`, `P3` 순서로 도면 포인트가 추가됩니다.
6. 포인트 표의 `순서` 핸들을 드래그해서 포인트 순서를 바꿀 수 있습니다.
7. 최소 4개 포인트에 실제 Pan/Tilt 값을 입력하고 `캘리브레이션 계산`을 누릅니다.
8. 계산 후 나머지 포인트의 Pan/Tilt가 자동 추정됩니다.
9. `Pan/Tilt -> X/Y 추정` 영역에서 특정 각도값에 대한 도면 좌표 추정값을 확인할 수 있습니다.

도면 포인트 데이터는 레시피 포인트와 별도로 저장됩니다. 필요할 때 `레시피로 내보내기`, `레시피에서 불러오기` 버튼으로 상호 변환합니다.

## 4. 업로드 진행률 표시

도면 업로드 중에는 다음 단계가 표시됩니다.

| 단계 | 의미 |
|---|---|
| 업로드 준비 | 파일명과 용량 확인 |
| 파일 업로드 | 브라우저에서 서버로 파일 전송 중 |
| 파일 형식 판별 | 서버가 확장자와 모델 구조를 확인 중 |
| 3D Mesh 변환 | 웹 뷰어에서 표시할 삼각면 생성 중 |
| 렌더링 최적화 | 큰 모델을 브라우저용 경량 mesh로 정리 중 |
| 서버 저장 | 원본 파일, mesh, 포인트 데이터를 최근 항목에 저장 중 |
| 모델 불러오기 | 저장된 mesh를 뷰어에 로드 중 |

서버 변환 단계는 단일 업로드 요청 안에서 처리되므로, 브라우저에는 단계별 예상 진행률로 표시됩니다. 실패하면 `변환 실패` 상태와 서버 오류 메시지가 표시됩니다. 한 파일의 업로드/변환 요청이 10분을 넘기면 브라우저가 타임아웃으로 중단합니다.

## 5. 3D 뷰어 조작

| 조작 | 동작 |
|---|---|
| 좌클릭 드래그 | 모델 회전 |
| 우클릭 드래그 | 화면 이동 |
| 마우스 휠 | 확대/축소 |
| 좌클릭 | 도면 포인트 추가 |
| 홈 버튼 | 등각 기본 시점으로 복귀 |

### 표시 모드

| 모드 | 용도 |
|---|---|
| 클린 CAD | 기본 모드. 밝은 배경, 면 색상 구분, 얇은 삼각선 제거 |
| 음영 | 기존 어두운 배경의 음영 표시 |
| 투시 | 내부/겹침 확인용 반투명 표시 |
| 와이어 | 삼각면/외곽 확인용 선 표시 |
| 점 | 면이 없거나 매우 무거운 모델 확인용 포인트 표시 |

### 시점 프리셋

`등각`, `정면`, `상면`, `아랫면`, `우측`, `후면` 시점을 선택할 수 있습니다. 우측 상단의 모의 위치 블록은 현재 모델 회전 상태를 따라 움직입니다.

### 품질 옵션

| 옵션 | 설명 |
|---|---|
| 빠름 | 큰 모델을 빠르게 회전할 때 권장 |
| 균형 | 기본값. 품질과 속도 균형 |
| 고품질 | 더 많은 면을 표시. PC 성능이 충분할 때 사용 |

드래그나 휠 조작 중에는 자동으로 가벼운 표시 품질을 사용하고, 조작이 끝나면 선택한 품질로 다시 그립니다.

## 6. 저장 위치

| 데이터 | Windows | Linux |
|---|---|---|
| 레시피 | `%LOCALAPPDATA%\OSRND\PT503Tester` | `${XDG_STATE_HOME:-~/.local/state}/OSRND/PT503Tester` |
| 도면 원본/mesh/포인트 | `%LOCALAPPDATA%\OSRND\PT503Tester\drawings` | `${XDG_STATE_HOME:-~/.local/state}/OSRND/PT503Tester/drawings` |
| STEP 변환 캐시 | `%LOCALAPPDATA%\OSRND\PT503Tester\mesh_cache` | `${XDG_STATE_HOME:-~/.local/state}/OSRND/PT503Tester/mesh_cache` |

최근 도면 목록은 서버 저장소 기준입니다. 브라우저 캐시를 지워도 서버에 저장된 도면은 유지됩니다.

## 7. 문제 해결

| 증상 | 확인할 것 |
|---|---|
| 업로드 후 변환 실패 | 파일 확장자, 파일 손상 여부, 서버 로그의 변환 오류 확인 |
| STEP/STP가 단색 또는 단순 형상으로 보임 | 서버에 FreeCAD/CadQuery가 없으면 내장 boundary 파서로 표시됩니다. 정밀 색상/곡면은 별도 변환 도구 설치 시 개선됩니다. |
| STEP/STP가 찢어진 삼각형처럼 보임 | RDK-X5 headless 환경에서 내장 STEP 미리보기 파서를 사용할 때 concave face나 구멍이 있는 face가 거대한 삼각형으로 보일 수 있습니다. 웹 뷰어는 비정상적으로 큰 면을 자동 숨김 처리하지만, 정밀한 솔리드 변환이 필요하면 FreeCAD/CadQuery 변환 환경을 별도로 구성해야 합니다. |
| `Error handling writeFile ... .venv/Lib/site-packages/PySide6/... light directional.png` | 앱 오류가 아니라 SSH/편집기가 원격 `.venv` 내부 PySide6 리소스 파일을 쓰려다 실패한 것입니다. `.venv`는 배포/동기화 대상에서 제외하고, RDK-X5 보드에서 `./run_linux.sh`로 Linux용 venv를 새로 만드세요. 서버 모드는 PySide6가 필요 없습니다. |
| 3D 뷰어가 느림 | 품질을 `빠름`으로 변경하고 `클린 CAD` 또는 `점` 모드로 확인 |
| 포인트가 찍히지 않음 | 모델이 로드되었는지, 너무 멀리 줌아웃되지 않았는지 확인 |
| 캘리브레이션 실패 | Pan/Tilt가 입력된 calibration 포인트가 최소 4개인지 확인 |

## 8. 검증 범위

현재 웹 콘솔은 하드웨어 없이도 레시피 저장, 도면 업로드 저장, STL 파싱, 캘리브레이션 계산 로직을 테스트할 수 있습니다. 실제 모터, RS485, 레이저, 게임패드 입력은 장비 연결 상태에서 별도 현장 검증이 필요합니다.
